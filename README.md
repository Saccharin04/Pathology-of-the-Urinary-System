# Renal Atlas · 泌尿病理图谱

采用 Apple 原生界面语言的中文教学网站：系统字体、留白、轻层次、深浅主题与响应式布局。

## 使用

- [网站](https://saccharin04.github.io/Pathology-of-the-Urinary-System/)
- 点击知识节点查看机制、形态、临床联系、辨析提醒及参考来源。选择节点时高亮带关系标签的连接；节点详情列出全部入边与出边。
- 分类或搜索可筛选节点并保留邻居；图谱支持缩放、横纵滚动和键盘 Enter/Space 选择。
- 问题支持三个层级筛选、前置问题跳转、返回知识节点、展开讨论要点和待复习标记。
- 手记及复习数据仅存于当前浏览器 localStorage，可导出 Markdown；没有账号、服务器、分析追踪或在线生成服务。
- 深浅主题默认跟随系统，手动选择后保存在本机。

## 本次内容与设计思路

病理模块包含26个知识节点、36条语义关系、18道问题（4道记忆、8道分析、6道应用）。按结构/方法、疾病病变、功能表型组织，覆盖肾小球、小管间质、血管梗阻和肿瘤；通过AKI、肾病综合征联系水钠和钾紊乱。此模块不是完整水电解质病理生理课程的替代品。

全部问题挂载知识节点；部分问题另有前置关系，组成递进问题网络。病例均为教学模拟，非真实患者资料。来源见网页及 data.js，形态学主参考 Robbins & Cotran Pathologic Basis of Disease, 10th ed.（2021）相关章节；另有KDIGO、NIDDK、NCI等来源。未对教材作逐页引用，不宣称指南是每个形态细节的唯一依据。

## AI 使用说明

使用 OpenAI Codex 辅助组织知识、编写 HTML/CSS/JavaScript 和检查节点关联。采用静态预编写内容，不调用在线大模型。人工提交者应依据课程教材审核；尚未经课程教师专业审阅。课堂讲评记录默认留空，仅在实际使用后填写。未提供原始图谱量化量规，不宣称满足未公开门槛或保证评分。

## 本地运行与发布

纯静态文件，无依赖、无构建步骤。在目录运行 `python3 -m http.server 8000` 后访问 `http://localhost:8000`，或直接打开 index.html。GitHub Actions 自动部署到 GitHub Pages；网站路径使用相对引用，适用于项目子路径。

`node --check app.js` 和 `node --check data.js` 检查语法，`node verify.mjs` 检查节点唯一性、关系、题目溯源、题目递进及必需文件。验证不代替医学专业审阅。

## 文件

- `index.html` / `style.css`：页面与视觉
- `data.js`：知识、关系、题目与资料
- `app.js`：图谱与学习交互
- `.github/workflows/pages.yml`：自动发布
